# Roadmap

## Implemented

- Phase 0 CLI foundation: `version`, `doctor`, help, JSON output, local tests, CI and project documentation.
- Phase 1 offline inspection of selected AWS CLI responses with a versioned JSON manifest, neutral inventory, and confirmed ECS dependencies.
- Phase 2 Compose compatibility rules, versioned reports, and an unexecuted migration plan.
- Phase 3 local Compose proposal generation for supported ECS container configuration and empty PostgreSQL services, with explicit partial and blocked reports.
- Phase 4 static verification, opt-in isolated runtime checks, and a synthetic HTTP/PostgreSQL demo.

## In development

- None currently.

## Planned

- Broader workload coverage and deployment suitability research; no additional phase is implemented.

## Exploratory

- Additional providers and targets, data transfer, and migration execution. These require separate design and validation.
